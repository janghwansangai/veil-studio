# Veil Studio — AI 어시스턴트용 소개·안내 문서

> 이 문서는 AI 어시스턴트(챗봇, 코딩 에이전트 등)가 Veil Studio를 정확히 소개하고 사용자 질문에 답하도록 돕는 참고 자료입니다.
> 기준 버전: **Mac 0.8.1**, **Windows 0.7.0** (2026-10 기준). 아래에 없는 기능은 "있다"고 답하지 마세요.

## 1. 한 줄 요약
Veil Studio는 아이들이 나오는 수업·행사 영상에서 **얼굴을 자동으로 찾아 가리고**, **한국어 음성을 자막으로** 만들어 주는 무료 데스크톱 영상 편집기입니다. 모든 처리는 사용자 컴퓨터 안에서 이루어집니다. 영상과 음성을 서버로 보내지 않습니다.

## 3. 주요 기능
1. **얼굴 자동 마스킹**: 모든 프레임에서 얼굴을 찾습니다. 정밀(기본)·표준·빠름 세 가지 모드가 있고, 모자이크·블러·단색·스티커 중에서 고를 수 있습니다.
2. **인물별 선택**: 찾은 얼굴을 사람 단위로 묶어 보여 줍니다. 가릴 사람만 체크하면 됩니다. 같은 시간에 함께 나온 얼굴은 한 사람으로 묶지 않습니다.
3. **영역 마스킹**: 사용자가 직접 영역을 그리고 키프레임으로 움직임을 지정해 가립니다.
4. **자동 자막**: 한국어 인식 결과를 읽기 좋은 길이로 자동 분할합니다. 불확실한 문장은 노란색으로 표시합니다. SRT 가져오기·저장, 영상에 자막 입히기를 지원합니다.
5. **여러 영상 편집(Mac)**: 영상·사진·오디오를 타임라인에서 편집합니다. 전환, 속도(10~1600%), 정지 화면, 화면 속 화면, 색 보정, 타이틀, 오디오 트랙을 지원합니다.
6. **순차 마스킹 작업 목록(Mac)**: 여러 영상을 차례로 처리합니다. 항목마다 "검토 후 출력" 또는 "자동 출력"을 고를 수 있고, 결과는 `원본이름_마스킹.mp4`로 저장됩니다.
7. **창 분리(Mac)**: 타임라인과 인물 선택 창을 다른 모니터로 분리할 수 있습니다. 인물 선택 창에서는 얼굴을 1~4배로 확대해 볼 수 있습니다.
8. **백그라운드 작업**: 분석·자막·내보내기가 진행되는 동안에도 편집할 수 있습니다.

## 4. 기본 사용 흐름 (사용자에게 안내할 순서)
1. 영상을 창에 끌어다 놓거나 `⌘O`로 엽니다.
2. **얼굴 마스킹** 탭에서 **얼굴 분석**(`⇧⌘F`)을 누르고, 가릴 인물을 체크한 뒤 **마스킹 적용**을 누릅니다.
3. 타임라인의 **주황색 구간**(얼굴을 놓쳤을 수 있는 곳)을 재생해 확인합니다. 빠진 곳은 영역 마스킹으로 보완합니다.
4. **자막 편집** 탭에서 **자동 자막**(`⇧⌘R`)을 누르고, 노란 표시 문장부터 고칩니다.
5. **내보내기**(`⌘E`)에서 비율(원본·16:9·9:16·1:1·4:3), 해상도(최대 4K), MP4/MOV, H.264/HEVC를 고릅니다.

여러 영상을 처리할 때는 **미디어** 탭에서 **모두 작업 목록에**를 누르고, **작업 목록** 탭에서 저장 폴더를 지정한 뒤 **순차 실행**을 누릅니다. 아이 영상은 **검토 후 출력**을 권장합니다.

## 5. 설치 안내
- **Mac**: zip 압축을 풀고 앱을 응용 프로그램 폴더로 옮깁니다. 처음 실행할 때는 앱을 **우클릭 → 열기 → 열기**로 엽니다(서명·공증 전 빌드라서 필요합니다). 그래도 막히면 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**를 누릅니다.
- **Windows**: exe를 실행합니다. SmartScreen 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 단축키는 `⌘` 대신 `Ctrl`을 씁니다.
- Windows 설치 파일 SHA256: `d9da50102d55d77e307e404f2f0318e64ae2b84f1b201b0c410898603362b6d2`

## 8. 지원 파일
- 입력: MOV·MP4·M4V(H.264·HEVC·ProRes), JPEG·PNG·HEIC·TIFF, M4A·WAV·MP3·AIFF
- MKV·WebM은 지원하지 않으므로 먼저 MP4로 변환하도록 안내합니다.
- 출력: MP4/MOV, 사진은 PNG/JPEG/TIFF/HEIC

## 9. 답변할 때 지켜야 할 원칙
- **"100% 가려진다"고 말하지 마세요.** 작은 얼굴, 옆얼굴, 가려진 얼굴은 놓칠 수 있습니다. 공유 전에 반드시 재생해서 확인하라고 안내하세요. 가장 안전한 방식은 단색 마스크입니다.
- 인터넷 없이 동작합니다. 예외는 macOS 26에서 Apple 인식기를 처음 고를 때 언어 자료를 내려받는 경우뿐입니다.
- 인텔 Mac, macOS 13 이하, 32비트 Windows는 지원하지 않습니다.
- 앱이 비정상 종료되면 다시 열 때 자동 저장본을 복구할지 묻습니다. 파일 메뉴의 "최근 자동 저장 복구"로도 복구할 수 있습니다.
- 모르는 내용은 추측하지 말고 웹사이트나 GitHub 저장소를 안내하세요.

## 10. 개발자 참고 (코딩 에이전트용)
- Mac 앱은 Swift/SwiftUI 앱이며 소스는 `Sources/VeilStudio/`에 있습니다. 렌더링은 AVFoundation과 커스텀 `AVVideoCompositing` 컴포지터로 합니다.
- 주요 파일: `FaceAnalysis.swift`(검출·추적), `Speech*.swift`(whisper.cpp·SpeechAnalyzer), `Compositor.swift`·`Rendering.swift`, `EditorStore*.swift`(상태), `BatchQueue.swift`(작업 목록), `DetachedWindows.swift`(창 분리)
- 테스트: `scripts/test.sh` (42개)
- 웹사이트: `website/` 폴더를 Cloudflare Workers 정적 자산으로 배포합니다(`npx wrangler deploy`). `worker/index.js`가 HTTP 요청을 HTTPS로 리다이렉트합니다.
- 제작: 다있쌤 로디 · 음성 인식: whisper.cpp / OpenAI Whisper(MIT) · Silero VAD(MIT)
