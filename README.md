# Veil Studio — macOS 얼굴·영역 마스킹 편집기

## v0.8 여러 소스 편집 / 얼굴 추적 / 고정확도 자막 / 작업 목록

### 여러 영상 소스
- ⌘O로 여러 파일(또는 폴더)을 고르면 순서대로 이어 붙인 새 프로젝트가 됩니다. 열린 프로젝트에는 ⌘I 또는 창·Dock 아이콘에 끌어다 놓아 추가합니다.
- **미디어** 탭: 썸네일·길이·해상도·사용 횟수·분석 상태를 보여 줍니다. 끝에 추가(E), 재생 위치에 삽입(W), 위 트랙에 연결(Q, 화면 속 화면), 독립 오디오로 추가, 타임라인으로 끌어다 놓기, 다시 연결(원본 이동 시), 제거를 지원합니다.
- 캔버스와 비율이 다른 영상(세로·가로 혼합)은 잘리지 않고 안쪽에 맞춰지며, 클립 검사기에서 ‘화면 채우기’를 고를 수 있습니다. 출력 탭에서 캔버스 크기·프레임률을 바꿉니다.
- 원본을 찾을 수 없어도 프로젝트는 열립니다. 해당 컷은 ‘미디어 없음’으로 표시되고 내보내기 전에 다시 연결을 요청합니다.

### 얼굴 마스킹
- 검출 + Vision 객체 추적: 검출이 놓친 프레임은 추적으로 이어 가고, 끊긴 구간은 같은 자리 근처일 때 최대 1초까지 보간합니다(마스크 탭에서 조절). 등장·퇴장 직전·직후 0.25초도 가립니다.
- 전역 매칭과 움직임 예측으로 추적을 잇고, 같은 시간에 함께 나온 얼굴은 절대 같은 인물로 묶지 않습니다. 목록은 인물 단위로 묶이고 펼쳐서 조각별로 확인·분리·병합(⌘클릭 후 묶기)합니다.
- 분석 모드: **정밀(기본·권장)** 화면 4분할 검출로 멀리 있는 작은 얼굴까지, 표준, 빠름.
- 몸은 보이는데 얼굴 추적이 끊긴 곳 등 **검토 권장 구간**을 타임라인 얼굴 줄(주황)과 목록에 표시합니다.
- 세로 촬영 영상(회전 정보)이 분석·출력에서 뒤집히던 문제를 고쳤습니다.
- 실제 98.7초 교실 영상 비교: 마스크가 적용된 프레임 82.9% → 표준 90.5% → 정밀 **98.7%**, 검출된 얼굴 수 3.2배(정밀).

### 자막
- 기본 엔진 **Whisper large-v3-turbo**(앱에 포함) + 음성 구간 검출(Silero VAD). 20초 조각 대신 최대 10분 단위로 인식하고 단어 단위 시간과 신뢰도를 받습니다. macOS 26에서는 Apple 새 인식기(SpeechAnalyzer)도 고를 수 있습니다.
- 잡음 섞인 한국어 합성 음성 글자 오류율: 기존 base 약 11% → turbo 약 2%.
- 공통 자막 분할기: 한 줄 글자 수·줄 수·쉼·문장부호 기준으로 나누고 두 줄을 균형 있게 맞춥니다. 무음 구간의 흔한 거짓 문장(“시청해 주셔서 감사합니다” 등)과 반복 문장을 거릅니다. 신뢰도가 낮은 문장은 노란색으로 표시합니다.
- 여러 소스의 음성을 각각 인식해 컷 위치·속도에 맞게 배치하고, 인식 결과를 소스별로 기억해 컷을 바꾼 뒤에는 새 구간만 인식합니다.

### 편집 (파이널 컷 참고)
- 타임라인 확대/축소(⌘=, ⌘-, ⇧Z, ⌥휠)와 가로 스크롤, 확대에 맞춘 시간 눈금, 필름스트립 썸네일, 소스별 오디오 파형.
- J/K/L 셔틀, ←/→ 1프레임, ⇧←/→ 10프레임, ↑/↓ 편집 지점, 마커(M, ⌃; ⌃'), 스냅(N), 자르기 도구(B)/선택 도구(A), 드래그로 순서·위치·트랙 변경.
- 클립 검사기: 속도(10%–1600%, 음높이 유지), 정지 화면(⌥F), 전환(크로스 디졸브·검은 화면·와이프·슬라이드, ⌘T), 영상 페이드, 위치·크기·회전·불투명도·자르기(미리보기에서 직접 끌기), 색 보정(노출·밝기·대비·채도·색온도·색조), 음량(dB)·페이드·소리 끄기·오디오 분리(⌃⇧S).
- 독립 오디오 트랙(배경음악·효과음), 타이틀(글꼴 크기·색·배경·위치·나타나기/사라지기, 미리보기에서 끌어 이동).

### 순차 얼굴 마스킹 작업 목록
- 미디어를 작업 목록에 넣고 ‘순차 실행’. 항목마다 **검토 후 출력**(분석 → 검토 창에서 확인·승인 → ‘승인 항목 출력’) 또는 **자동 출력**(분석 → 전원 마스킹 → 지정 폴더 저장)을 고릅니다.
- 출력 이름은 `원본이름_마스킹.mp4`, 같은 이름이 있으면 번호를 붙여 절대 덮어쓰지 않습니다. 실패한 항목은 이유를 남기고 다음 항목을 계속합니다.

### 안정성
- 자동 저장을 1.5초 뒤 별도 스레드에서 수행, 비정상 종료 후 다음 실행 때 복구 제안, 오류 기록(~/Library/Logs/VeilStudio), 긴 작업 중 잠자기 방지, 내보내기 전 디스크 여유 공간 확인.
- 슬라이더 드래그 한 번은 실행 취소 한 번으로 묶입니다(최대 60단계).
- 프로젝트 형식 v2: 기존 .veilproject는 자동 변환되어 열립니다(얼굴 데이터 압축 저장). v0.8에서 저장한 파일은 0.7에서 열 수 없습니다. 이전 앱은 `output/이전버전_Veil Studio 0.7.app`에 보관했습니다.

SwiftUI / AVFoundation / Vision / Core Image / Apple Speech로 만든 로컬 편집기입니다. 영상·이미지를 서버로 업로드하지 않으며 원본 대신 새 파일을 내보냅니다. macOS 14 이상이 대상이고, 제공 앱은 Apple Silicon용 개발 빌드입니다.

## v0.7 연결 세트 / 빈 구간 / Whisper

- 눈금과 트랙이 하나의 너비를 공유하여 스크롤바 유무에 따른 재생 헤드 오차를 없앴습니다.
- 영상 번호마다 **영상·오디오·얼굴 마스크** 3행을 표시합니다. 하나를 선택하면 같은 컷의 세 행이 함께 선택되고 분할·삭제·다른 트랙 이동도 함께 반영됩니다. 수동 영역 마스크와 자막은 기존처럼 독립 편집합니다.
- 영상/오디오/얼굴 행의 빈 구간을 우클릭해 **빈 구간 삭제 후 붙이기**를 실행합니다. 해당 영상 세트의 뒤 컷만 앞으로 이동합니다. 다른 영상 트랙·독립 자막·수동 영역의 시간은 유지하고 실행 취소할 수 있습니다.
- 미리보기와 타임라인 사이 9px 구분선을 위아래로 드래그해 타임라인 높이를 조절합니다. 높이는 다음 실행에도 유지됩니다.
- **자막 편집 → 인식 방식 → Whisper · 기기 내**가 추가됐습니다. Apple 권한/서비스와 별도로 작동하며, 기본 다국어 base 모델과 실행 파일을 앱에 포함했습니다. 네트워크로 음성을 전송하지 않습니다. Apple 인식도 선택 가능합니다.
- 기존 **최대 15초 시험 인식**은 Whisper에서도 동작하며 기존 자막을 바꾸지 않습니다. 전체 자동 자막은 트랙에 남은 구간을 대상으로 기존 자막을 교체하므로 먼저 저장하세요.
- 모델 선택에서 whisper.cpp 형식의 다국어 ggml 모델로 교체할 수 있습니다. 영어 전용 `.en` 모델은 한국어용이 아닙니다. 배경 음악·겹친 대화에서는 Whisper도 오인식/환각이 생길 수 있어 내용을 검토해야 합니다. 모델/실행기 출처와 라이선스는 `Resources/Speech/`에 포함했습니다.

## v0.6.1 눈금·휠·오디오 파형

- 고정 시간 눈금에 큰 눈금 7개와 작은 눈금을 표시하고, 클릭·드래그 영역 높이를 44px로 넓혔습니다.
- **시간 눈금 위에서 휠/트랙패드**를 움직이면 재생 위치가 이동합니다. Shift+휠은 1/10 간격으로 미세 이동합니다. 트랙 목록 위의 세로 휠은 기존처럼 트랙을 스크롤합니다.
- **오디오 · 영상 연결** 행은 원본의 첫 번째 오디오 스트림 파형을 표시합니다. 영상 컷의 분할·삭제·재배치와 함께 반영되며 영상이 겹치면 위쪽 영상의 오디오 구간을 보여줍니다. 독립 오디오 파일 추가/믹싱 기능은 포함하지 않습니다.
- 파형은 남아 있는 구간만 백그라운드에서 읽습니다. 원본 파형 캐시는 최대 120,000개 값(약 0.48MB)으로 제한하고, 화면에 그릴 파형은 폭·컷 구성·파형 데이터가 바뀔 때만 다시 만듭니다. 자막/마스크 수정과 매 재생 프레임마다 오디오를 다시 읽지 않습니다.

## v0.6 고정 눈금 / 음성 조정 / 출력 형식

- 편집 시간 눈금과 내보내기 I/O 손잡이는 트랙의 세로 스크롤 밖에 고정됩니다. 트랙만 스크롤하며 눈금 클릭으로 재생 위치를 지정합니다.
- **자막 편집 → 음성 인식 미세 조정**에서 분석 길이(10/20/45초), 증폭(0.25–4배), 오디오 트랙 번호, 고유명사·전문용어 힌트를 조절합니다. 설정은 현재 앱 실행 중 유지됩니다.
- **현재 위치부터 최대 15초 시험 인식**은 현재 영상 컷 안에서만 시험하고 기존 자막을 유지합니다. 말소리가 작다면 1.5–2배로 시험하고, 실패가 반복되면 10초 구간과 실제 발화 언어를 선택하세요. 오디오 트랙은 영상 레이어가 아니라 원본 파일 안의 오디오 스트림 번호입니다.
- 권한 확인·인식기 준비 단계를 따로 표시합니다. macOS 권한 응답이 오지 않으면 30초 후 안내하고 취소할 수 있습니다. 권한 오류는 증폭으로 해결되지 않습니다.
- 분석용 오디오를 16kHz 모노 PCM으로 변환합니다. 분석에만 증폭을 적용하고 원본/출력 음량은 바꾸지 않습니다. 평균·최대 신호(dBFS), 과증폭 비율을 진행 상태와 말소리 미검출 진단에 표시합니다. 신호가 크다고 음성이 있다는 뜻은 아니며, 음악도 신호에 포함됩니다. 음악 분리/음성 인식 성공을 보장하는 설정은 아닙니다.
- 영상 출력: **MP4 / MOV**, H.264 또는 HEVC. 이미지 출력: **PNG / JPEG / TIFF / HEIC**. 실제 내보내기 시 이 Mac의 인코더 지원 여부를 확인합니다. 기존 프로젝트의 PNG/JPEG·MP4 설정도 호환됩니다.
- 가져오기 대화상자는 기타 확장자도 선택할 수 있습니다. 실제 지원은 AVFoundation/ImageIO의 디코더에 따릅니다. MOV/MP4/M4V, JPEG/PNG/HEIC/TIFF/BMP 등이 대상이며 MKV/WebM 지원 코덱을 별도로 추가한 것은 아닙니다. 애니메이션과 다중 페이지 이미지는 계속 제한됩니다.

## v0.5.1 저장 보호와 안정성

- 저장하지 않은 프로젝트는 창 닫기(⌘W/닫기 버튼), 앱 종료(⌘Q), 새 미디어 열기/드롭, 다른 프로젝트 열기/복구 전에 **저장 / 저장하지 않음 / 취소**를 묻습니다. 저장창 취소나 저장 실패 시 전환하지 않습니다.
- 실제 디스크 저장 성공 시에만 저장 완료로 처리합니다. 저장한 상태로 실행 취소하면 변경 표시도 해제됩니다. 자동 복구 저장은 수동 프로젝트 저장과 구분합니다.
- 영역 상세창이 열린 상태에서 새 미디어를 불러올 때 발생한 배열 범위 초과 충돌을 수정했습니다. 자막·영역의 편집 연결은 항목 ID와 프로젝트 세션을 확인하여, 삭제·재정렬·프로젝트 교체 후 늦게 도착한 입력을 무시합니다.
- 새 프로젝트 전환 시 미리보기 작업, 플레이어 탐색, 영상 구성 캐시, 이전 선택·클립보드를 정리합니다. 취소된 미리보기 작업이 새 프로젝트의 캐시를 덮어쓰지 않도록 했습니다.
- 분석·내보내기 중에는 완료 또는 취소 후 종료/전환할 수 있습니다. 새 파일 읽기에 실패하면 기존 프로젝트는 유지됩니다.

## v0.5 여러 트랙과 남은 구간 분석

- **트랙 추가**에서 영상·영역 마스크·자막 트랙을 추가합니다. 블록을 우클릭해 **트랙으로 이동 → 기존/새 트랙**을 선택합니다. 영상 컷은 빈 영상 트랙으로 드래그해서 시간과 트랙을 바꿀 수도 있습니다.
- **겹친 항목 분리**는 자막·영역이 겹칠 때만 다른 트랙을 배정합니다. 겹치지 않는 기존 항목의 트랙·시간·내용은 유지됩니다. 새 항목 추가와 시간 드래그 완료 시에도 겹침을 정리합니다.
- 위쪽 영상 트랙이 아래 영상을 덮습니다. 현재 영상 트랙들은 **같은 원본 파일의 컷**을 배치하는 기능입니다. 서로 다른 파일을 함께 불러오기, 화면 속 화면, 투명도 합성, 오디오 트랙 믹싱은 포함하지 않습니다. 겹친 구간은 위쪽 영상과 그 음성을 사용합니다.
- 영상 트랙이 여러 개이면 컷 삭제 시 다른 트랙의 위치를 유지하며 빈 구간은 검은 화면이 됩니다. 한 영상 트랙일 때는 기존 자동 붙이기를 유지합니다.
- 자막은 여러 트랙을 함께 렌더링합니다. 화면 위치가 같으면 글자도 겹칠 수 있으므로 자막 위치 설정에서 배치하세요. 영역 효과는 아래 트랙부터 위 트랙 순서로 적용됩니다.
- 블록 선택 시 해당 자막/영역의 상세 항목으로 스크롤합니다. 미리보기 편집 틀은 선택 항목의 시작 이상, 종료 미만에서만 표시됩니다.
- 얼굴·음성 분석은 트랙에 남아 있는 원본 구간의 합집합만 처리합니다. 반복 사용된 원본 구간은 한 번만 분석합니다. 가려진 하위 영상 트랙도 나중에 드러날 수 있으므로 트랙에 존재하면 분석 대상입니다. 내보내기 I/O 선택 범위와 분석 범위는 별개입니다.
- 분석 이후 컷을 늘려 아직 분석하지 않은 원본 구간을 추가했다면 다시 분석하세요. 분석 정확도는 기존과 같으며 배경음악 분리는 지원하지 않습니다.
- 프로젝트는 기존 버전과 호환해서 읽고, 트랙 번호·영상 배치 시간을 저장합니다. 새 버전에서 저장한 다중 트랙 프로젝트는 이전 앱으로 편집하지 마세요.

## 얼굴 분석의 중요한 한계

`VNDetectFaceRectanglesRequest`로 얼굴을 찾고, 위치 연속성과 `VNGenerateImageFeaturePrintRequest`의 일반 이미지 특징을 함께 사용해 인물 후보를 연결합니다. **전용 얼굴 신원 임베딩 모델을 사용한 인물 인식은 아닙니다.** 인물이 다시 등장하거나 각도가 달라지면 여러 후보로 나뉠 수 있고, 비슷한 얼굴은 잘못 묶일 수 있습니다. 후보 그룹 묶기는 같은 이름으로 선택 상태를 함께 제어하며, 동시에 나타난 영역을 잃지 않도록 원래 검출 트랙을 모두 보존합니다.

검출 입력은 영상의 경우 긴 변 최대 960px, 이미지의 경우 최대 2400px입니다. 이미지는 겹치는 9개 영역도 추가 분석해 작은 얼굴 검출을 보완합니다. 작은 얼굴·빠른 움직임·가림·옆얼굴·장면 전환에서 놓칠 수 있습니다. 전체 프레임을 분석한다는 것이 모든 얼굴을 반드시 검출한다는 뜻은 아닙니다. 결과를 검토하고 수동 영역과 키프레임으로 보완해야 합니다. 하트/별 마스크는 모서리가 비어 있으므로 충분한 여백이 필요합니다. 블러·모자이크보다 단색 사각형이 얼굴 정보를 가리는 데 확실합니다.

아이들의 영상 등 실제 영상으로 인물 분류 정확도와 검출 누락률을 측정하기 전에는 완전 자동 익명화 제품으로 간주하면 안 됩니다.

## 자막

- Apple Speech 권한과 해당 언어의 `supportsOnDeviceRecognition`이 필요합니다.
- `requiresOnDeviceRecognition = true`로 설정합니다. 지원되지 않을 때 서버 인식으로 전환하지 않습니다.
- 한국어·영어·일본어를 선택할 수 있습니다. 실제 지원 여부는 Mac과 설치된 언어 리소스에 따라 달라집니다.
- 긴 영상은 45초 오디오 조각으로 순차 처리합니다. 조각 경계의 단어와 정확한 타이밍은 검토해야 합니다.
- `No speech detected` 구간은 건너뛰고 다음 45초 구간을 계속 분석합니다. 음악만 있는 도입부 때문에 영상 전체가 중단되던 문제를 수정했습니다.
- 부분 인식 뒤 오류가 발생하면 확보된 자막을 유지하고, 자막 패널의 **인식 결과 · 검토할 구간**에 표시합니다. 모든 구간에서 말소리를 찾지 못하면 기존 자막을 유지합니다.
- 음성 권한 거부·언어 미지원·오디오 없음·시간 초과는 별도로 안내합니다. 배경음악과 사람 목소리를 분리하는 기능은 없습니다.
- SRT를 불러오는 경우 편집 타임라인 시간을 사용합니다. 지정 내보내기 구간에는 SRT 시간도 맞춰집니다.
- 자동 인식 결과는 현재 영상 컷의 편집 시간에 맞춰 저장됩니다. 실제 음성 인식의 정확도와 권한 흐름은 사용자 Mac에서 확인해야 합니다.

## 어느 용량까지 편집할 수 있나요?

**파일당 GB 제한을 코드에 두지 않았습니다. 하지만 현재 보장할 수 있는 최대 GB·최대 영상 시간은 실측하지 않았습니다.**

영상은 `AVAssetReader`가 한 프레임씩 읽습니다. 따라서 10GB 파일을 열기 위해 10GB를 통째로 RAM에 적재하지는 않습니다. 다만 얼굴 프레임별 좌표·썸네일·프로젝트 데이터는 메모리에 남습니다. 긴 영상·많은 사람·많은 검출 트랙은 메모리와 프로젝트 저장량을 늘립니다. 인식 시간이 영상 길이보다 길어질 수 있습니다.

| 항목 | 현재 구현 범위 / 한계 |
| --- | --- |
| 영상 입력 용량 | 별도 GB 제한 없음. 파일 시스템·코덱·RAM·임시 디스크에 좌우됨 |
| 영상 길이 | 별도 시간 제한 없음. 장시간 영상의 안정적 최대치는 미검증 |
| 이미지 | 단일 프레임 최대 120,000,000화소(1억 2천만 화소) |
| 해상도 | 원본 또는 긴 변 최대 3840/1920/1280px. 원본보다 확대하지 않음 |
| 출력 프레임률 | 원본 명목 프레임률 기준, 최대 120fps |
| 4K 8비트 BGRA 버퍼 | 3840 × 2160 × 4바이트 ≈ 31.6MiB / 프레임 |
| 8K 8비트 BGRA 버퍼 | 7680 × 4320 × 4바이트 ≈ 126.6MiB / 프레임 |
| 1억 2천만 화소 이미지 | RGBA 버퍼 하나만 ≈ 458MiB. 효과 계산은 복수 버퍼 사용 |
| 저장 공간 | 최종 출력 크기 + 임시 파일 + 프로젝트 데이터 공간 필요 |

영상 예: MOV/MP4/M4V의 H.264, HEVC, ProRes 등 **macOS AVFoundation이 실제로 디코딩하는 조합**. 컨테이너 확장자만으로 지원을 보장하지 않습니다. MKV/WebM/일부 AVI는 MP4/MOV 변환이 필요합니다.

이미지 예: JPEG, PNG, HEIC, TIFF, BMP, 시스템 ImageIO가 지원하는 WebP/RAW 등. 애니메이션 GIF·다중 페이지 이미지는 첫 장만 몰래 처리하지 않고 명시적으로 거절합니다. 출력은 PNG 또는 JPEG입니다.

HDR/광색역 원본의 색 보존은 보장하지 않습니다. 현재 출력은 SDR 편집 경로입니다. 영상 비트레이트를 직접 지정하는 기능은 없으며 고품질 인코더 프리셋을 사용합니다. 출력 파일 용량은 내용과 코덱에 따라 달라집니다.

## 프로젝트와 개인정보

원본은 프로젝트 파일에 포함되지 않습니다. 원본 경로, 크기, 수정 날짜를 저장하며 변경된 원본을 감지하면 재분석을 요구합니다. 원본을 이동하지 마세요.

화면 가장자리 밖으로 일부 나간 얼굴 검출 좌표는 열기·저장·내보내기 시 화면 범위 안으로 보정합니다. 양수가 아닌 크기, 비정상 숫자 등 실제 잘못된 데이터는 계속 거절합니다.

자동 복구 파일은 `~/Library/Application Support/VeilStudio/Recovery.veilproject`입니다. **원본 경로·얼굴 썸네일·분석 좌표·자막이 포함**됩니다. 작업 종료 후 민감한 프로젝트와 복구 파일은 사용자가 관리해야 합니다. 영상·이미지 출력에는 원본 EXIF/GPS 메타데이터를 의도적으로 복사하지 않습니다.

## 빌드·검증

```sh
./scripts/build.sh
./scripts/test.sh
```

Xcode Command Line Tools와 Swift가 필요합니다. CLT 27에 SwiftUI macro plugin이 없는 환경에서는 설치된 26.5 SDK를 자동 선택합니다. 다른 SDK는 `VEIL_SDK_PATH`로 지정할 수 있습니다. 앱은 별도의 외부 패키지에 의존하지 않습니다.

`test.sh`는 XCTest가 없는 CLT 환경에서도 실제 Core Image/AVFoundation을 사용해 픽셀, 컷 시간, 크롭, 취소, 세로 영상 방향을 검증하는 실행형 테스트입니다. 전체 Xcode 환경에서는 `Tests/VeilStudioTests`의 XCTest를 사용할 수도 있습니다. 확인된 결과는 `VALIDATION.md`에 기록합니다.

## 설계

- `Models.swift`: 정규화 좌표, 후보 트랙, 키프레임, 컷, 자막, 프로젝트 직렬화, SRT 변환.
- `MediaEngine.swift`: 스트리밍 얼굴 분석, 마스크 렌더링, 원본 방향 적용, 컷 합성, 이미지/영상 내보내기.
- `Transcription.swift`: 권한 확인, 기기 내 인식, 45초 오디오 조각, 취소/시간 초과 처리.
- `Timeline.swift`, `TimelineView.swift`: 편집 시간 매핑, 컷 조작, 내보내기 범위와 타임라인 UI.
- `EditorStore.swift`: 프로젝트 상태, 미리보기, 실행 취소, 파일 입출력, 자동 복구.
- `EditorView.swift`, `PreviewTimeline.swift`, `Inspector.swift`: 네이티브 SwiftUI 편집 화면.
